# 考研·六级背单词 App

为同时备考考研英语一与英语六级的大三学生定制:
- 词库: 考研大纲5528词 ∪ 六级词表3991词, 合并去重后 6830 词
- 真实词频标注: 考研重点(约200套真题文本词频>=40) / 六级重点(2020-2025年35套真题词频>=5) / 双重点 / 普通
- 记忆法: 词根词缀拆解 + 真题情景例句, SM-2间隔重复调度
- 拼写练习: 看释义+听美音写单词, 例句挖空提示, 逐字母标错, 拼错/用提示的词进入待巩固并优先出题
- 界面: 简约干净的中性灰阶 + 单一蓝色强调, 自动深色模式, 键盘快捷键(学习: 空格翻面 / 1 2 3 作答 / P 发音 / Esc 退出; 拼写: Enter 确认 / ↑ 重听), 进度存本地

## 数据来源(致谢)
- [exam-data/NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary) - 考研5530大纲词+真题词频 (CC BY-NC-SA 4.0, 数据部分)
- [wangjiuyi543-ui/cet6-vocabulary](https://github.com/wangjiuyi543-ui/cet6-vocabulary) - 六级2020-2025真题词频+真题例句 (MIT)
